即時校園地圖通知系統 — 系統架構

Real-Time Campus Map Notification System · WebSocket + Redis GEO + Pub/Sub

🌐 前端架構 Frontend

  • • React + Leaflet 互動式校園地圖
  • • GPS 定位 (Geolocation API)
  • • WebSocket 即時通知接收
  • • 事件回報表單 (事件/活動/公告)
  • • 斷線自動重連 + 離線佇列重播

⚙️ 後端服務 Backend

  • • 定位服務 :8001 — GPS 座標 → Redis GEO
  • • 事件服務 :8002 — 建立事件 → Redis LIST + Pub/Sub
  • • 通知服務 :8003 — 訂閱頻道 → GEOSEARCH → WS 推播
  • • nginx 反向代理 :8080→:8095 路由分發
  • • Gunicorn 多 Worker 併發處理

⚡ 資料層 Data Layer

  • • Redis GEO — 使用者即時位置儲存與查詢
  • • Redis LIST — 事件持久化、評論、離線佇列
  • • Redis Pub/Sub — event_channel 即時事件廣播
  • • GEOSEARCH 附近使用者匹配
  • • 記憶體內運算，微秒級延遲

☁️ 外部服務 External

  • • Cloudflare Tunnel — 安全通道連線
  • • map2.avision-gb10.org 自訂域名
  • • TLS 加密終端 · DDoS 防護
  • • 無需開放本地端口
  • • 自動 HTTPS 憑證管理

📡 即時通訊 Real-Time

  • • WebSocket 雙向即時通訊
  • • Pub/Sub 解耦：事件服務 ↔ 通知服務
  • • GEOSEARCH 半徑內使用者篩選
  • • 離線通知自動佇列排程
  • • 重連後無縫重播未讀通知

🔒 安全與部署 Security

  • • Cloudflare TLS 加密傳輸
  • • nginx 作為統一入口閘道
  • • Docker Compose 容器化部署
  • • 內部服務不對外暴露端口
  • • DGX Spark 邊緣運算部署
