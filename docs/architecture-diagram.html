即時校園地圖通知系統 — 系統架構圖

Real-time Campus Map Notification System · Microservices + Redis Pub/Sub

後端微服務

  • • Location Service — GPS 座標存取、附近使用者查詢
  • • Event Service — 事件建立/查詢、留言、過期管理
  • • Notification Service — WebSocket、離線佇列、推播
  • • Gunicorn 4/4/1 workers（多核利用）

Redis 資料策略

  • • GEO — 使用者座標空間索引（半徑查詢）
  • • LIST — 事件歷史（最新 100 筆）、離線佇列
  • • PUB/SUB — 事件推播（取代 HTTP fanout）
  • • Connection Pool max=20，graceful shutdown

部署與效能

  • • Docker Compose + nginx 反向代理
  • • Cloudflare Tunnel（HTTPS + DDoS 防護）
  • • 500 人壓測 100% 成功率、277 RPS
  • • 記憶體佔用 ~470MB
