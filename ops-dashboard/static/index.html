模式說明

k8s 模式：讀取真實 HPA 與 kubectl top，CPU% 以 Pod 的 CPU requests 為基準（與 HPA 相同）， 壓測以 load-generator Job 在叢集內發動。HPA 依指標週期反應，擴展通常需 15–60 秒，縮減約 5 分鐘。
compose 模式：HPA 由 ops 服務模擬，平均 CPU 超過門檻連續 2 次才擴展（最多 5 副本）， 停止壓測後縮回 1 副本；額外副本發布於 :18001–:18004，壓測流量經 ops 的 round-robin proxy 分流。
